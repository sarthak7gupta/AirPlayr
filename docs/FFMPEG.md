# MKV Bridge & FFmpeg LGPL Compliance

AirPlayr bundles separate `ffmpeg` and `ffprobe` command-line executables built from official **FFmpeg 9.0.2** source. The build disables GPL components, nonfree codecs, external third-party libraries, and all network protocols. Both executables are licensed under the **GNU Lesser General Public License (LGPL) version 2.1 or later** ([`Vendor/FFmpeg/Licenses/`](../Vendor/FFmpeg/Licenses/)).

## How the MKV Bridge Works

1. AirPlayr opens the user-selected media file read-only and passes a seekable file descriptor (`fd:0`) to `ffprobe` / `ffmpeg`.
2. H.264 and HEVC video streams inside `.mkv` containers are remuxed into 6-second temporary fragmented MP4 sections without video re-encoding at the demux stage, while audio is normalized to stereo AAC.
3. Apple's hardware-accelerated `AVAssetReader` and `AVAssetWriter` (`VideoToolbox`) generate VOD HLS segments with timestamps rebased to the full movie timeline.
4. Embedded SubRip (`subrip`) and MPEG-4 Timed Text (`mov_text`/`tx3g`) tracks are extracted into selectable WebVTT tracks.

## Reproducing the Bundled Helpers

Requires macOS and Xcode Command Line Tools:

```sh
task media-tools
# or directly:
/bin/bash scripts/build-media-tools.sh
```

The build script verifies the pinned SHA-256 checksum (`8c3850283eb25fa026482078a04051e0be17347b09ef81a0849bec15a96e002e`) of `Vendor/FFmpeg/Source/ffmpeg-9.0.2.tar.xz`, compiles `arm64` and `x86_64` slices, and merges them into universal Mach-O binaries with `lipo`.

## LGPL v2.1 Distribution

- AirPlayr invokes `ffmpeg` and `ffprobe` as separate child processes and does not link FFmpeg libraries into the Swift executable.
- Release DMGs generated by `task dmg` include `Open Source/FFmpeg/` containing the complete unmodified FFmpeg 9.0.2 source archive, per-architecture configuration headers, LGPL v2.1 license texts, and `scripts/build-media-tools.sh`.
