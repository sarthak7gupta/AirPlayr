Build, Install & FFmpeg LGPL Guide

AirPlayr ships ready-to-build in Xcode with bundled universal LGPL v2.1+ FFmpeg 9.0.2 command-line helpers—no Homebrew dependencies required.

Everyday Build & Verification Commands

# Build universal (arm64 + x86_64) Release AirPlayr.app
task build
# Run the full XCTest suite
task test
# Verify universal binary compatibility & code signature
task verify
# Build & install AirPlayr.app into /Applications
task install
# Package drag-to-Applications DMG (includes Open Source/FFmpeg bundle)
task dmg

Bundled FFmpeg 9.0.2 Helpers & LGPL v2.1 Compliance

  • Separate Child Executables: AirPlayr bundles ffmpeg and ffprobe in Contents/MacOS/ and invokes them as separate processes via read-only file descriptors (fd:0). AirPlayr does not link FFmpeg libraries into the Swift application binary.
  • Minimal LGPL v2.1+ Configuration: Built from official FFmpeg 9.0.2 source (SHA-256: 8c3850283eb25fa026482078a04051e0be17347b09ef81a0849bec15a96e002e) with GPL, nonfree, external libraries, and all network protocols disabled.
  • Reproducible Build Recipe: Run task media-tools (or /bin/bash scripts/build-media-tools.sh) to verify the pinned archive checksum, compile arm64 and x86_64 slices, and merge them with lipo.
  • Complete Corresponding Source: Included in the repository under Vendor/FFmpeg/Source/ and packaged inside every release DMG under Open Source/FFmpeg/.
