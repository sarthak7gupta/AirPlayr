COMPILATION GUIDE &
SOURCE TARGETS.

AirPlayr is structured as an idiomatic Swift Xcode project for macOS. The universal binary runs natively on both Apple Silicon (M1–M5) and Intel architectures.

01 // Compiling macOS Target

COMMAND // XCODEBUILD RELEASE
SHELL // BUILD UNIVERSAL MAC DMG APPLE SILICON & INTEL

Clone repository and build with xcodebuild:

git clone https://github.com/sarthak7gupta/AirPlayr.git
cd AirPlayr
xcodebuild build -scheme AirPlayr -configuration Release -destination 'generic/platform=macOS' CODE_SIGN_IDENTITY="-" CODE_SIGNING_REQUIRED=NO

Create standalone Universal .dmg installer:

./scripts/create-dmg.sh

02 // Mobile Companion Target

ALPHA BRANCH // EXPERIMENTAL TARGET
SHELL // MOBILE PLATFORMS ALPHA BRANCH

The experimental iOS / iPadOS companion app is developed and maintained on the alpha branch:

git checkout alpha

03 // Automated XCTest Suite

TEST SUITE // CONTINUOUS INTEGRATION
TEST.01

Streaming Engine

Verifies zero-re-encode fMP4 muxing, segment byte-alignment, m3u8 playlist generation, and socket HTTP ranges.

TEST.02

Format Matrix

Tests Matroska, MP4, MOV, HEVC, and AV1 video fixtures against the track demuxer and subtitle parser.

TEST.03

Cast & DLNA Wire

Validates CastV2 Protobuf message round-trip, UPnP SSDP device location discovery, and AVTransport parsing.
