RELEASE // LATEST

Version 1.6.0

OCTOBER 2026
Subsystem Architectural Changes & Improvements
Branch Strategy Repository main branch streamlined to focus exclusively on macOS. Experimental mobile targets moved to dedicated alpha branch.
Multichannel Audio Enabled true bit-perfect 5.1 and 7.1 surround sound passthrough across all stream sessions and MKV bridge with zero downmixing to stereo. Mapped 6-channel to kAudioChannelLayoutTag_MPEG_5_1_D and 8-channel to kAudioChannelLayoutTag_MPEG_7_1_B.
Format Expansion (Mac) Added support for Blu-ray/AVCHD transport streams (.m2ts, .ts, .mts), HLS playlists (.m3u8), DVD video objects (.vob), disc images (.iso with auto-mount), and raw Dolby AC-4 (.ac4).
UI & Brand Consistency Unified wordmark typography and electric cyan-to-blue gradient across macOS app and web. Refactored website navigation into an uncluttered 2-tier architectural system.
Protocol Core Hardened CastV2 Protobuf message serialization over TLS port 8009 and UPnP AVTransport:1 SSDP multicast device discovery.
RELEASE

Version 1.5.0

OCTOBER 2026
Subsystem Architectural Changes & Improvements
In-Memory fMP4 Direct stream copy ring-buffer segmenter. Remuxes Matroska container clusters into fragmented MP4 chunks in RAM with zero disk writes.
Subtitles Integrated OpenSubtitles REST API with 64-bit movie hash calculation. Added custom SubtitleAppearance editor with live preview.
Keyboard Deck Native macOS keyboard controls: Space for play/pause, Left/Right arrows for ±10s skip, M for mute, Cmd+F for native full screen.
RELEASE

Version 1.4.0

SEPTEMBER 2026
Subsystem Architectural Changes & Improvements
Compatible Export One-click export tool converting complex containers to universal H.264/AAC MP4 using Apple VideoToolbox hardware encoder.
App Sandbox Enforced Apple App Sandbox isolation, security-scoped bookmark persistence, and zero outgoing WAN network telemetry.
