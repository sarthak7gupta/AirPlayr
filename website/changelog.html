Release History & Changelog

Every AirPlayr release runs 100% locally with no login, no internet requirement, and zero telemetry.

AirPlayr v1.7.0 Latest Release
October 27, 2026 · Build 8

New in v1.7.0

  • Zero-Re-Encode 1080p / 4K Video Passthrough: Compressed H.264 and HEVC packets are muxed directly into fMP4 HLS segments when no pixel burn-in is needed, and hardware encoding preserves up to 4K (3840×2160).
  • Playlists & Up Next Queue (⌘[ / ⌘]): Open multiple files or folders into a sidebar Up Next Queue with automatic episode advance.
  • Live Subtitle Sync Offset (±0.25s) & Preferred Languages: Adjust caption timing on the fly and automatically select preferred audio/subtitle languages.
  • macOS Media Keys, Control Center & AirPods: Full integration with MPNowPlayingInfoCenter and MPRemoteCommandCenter.
  • Automatic SSDP Discovery for Miracast / DLNA TVs: Discovers UPnP MediaRenderer Smart TVs automatically over UDP multicast (239.255.255.250:1900).
  • Embedded ASS / SSA Subtitles & AV1 Hardware Support: Extracts embedded ASS/SSA tracks and enables hardware-decoded AV1 MKV streaming on M3/M4+ Macs.
  • Opt-In OpenSubtitles Search: Computes 64-bit movie hashes locally and stores API keys in the macOS Keychain.
  • Cross-Platform Desktop & Mobile: Added native Windows & Linux desktop application, native iOS/iPadOS target, native Android app, and a 100% client-side Web Player.
AirPlayr v1.6.0
October 27, 2026 · Build 7

New Features

  • Chromecast & Miracast / DLNA Streaming: Local discovery and playback control for Chromecast devices and UPnP/DLNA smart TVs on your Wi-Fi, plus manual IP connection and a quick shortcut to macOS Wireless Display settings.
  • Prevent Mac from Sleeping While Playing: Automatically keeps your Mac and display awake during active local playback, AirPlay routing, and Cast sessions, configurable in Settings and the Playback menu.
  • Automatic Temporary Cache Cleanup: Sweeps leftover temporary streaming folders on launch so interrupted sessions never waste disk space.

Reliability & Security Hardening

  • Single-Track MKV Audio Mapping: Maps only the selected audio stream (-map 0:a:<index>?) so unsupported secondary tracks never interrupt playback.
  • Embedded Timed-Text Subtitles: Enabled movtext decoder in bundled FFmpeg 9.0.2 helpers so MP4/MOV tx3g/mov_text subtitles are preserved during hev1 normalization.
  • Cancellation & Subprocess Safety: Serialized AVAssetReader.cancelReading() after reader pump completion and guaranteed 1-second SIGKILL escalation + waitUntilExit() in MediaToolRunner.
  • LAN HTTP Server Hardening: Prioritized physical en0/en* interfaces over virtual bridges, evicted unauthenticated idle connections under load, and removed NSAllowsArbitraryLoadsForMedia.
