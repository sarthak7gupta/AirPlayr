ZERO TELEMETRY.
HARDENED SANDBOX.

AirPlayr is designed from first principles as an offline-first tool. It contains zero tracking analytics, zero external network beacons, and operates strictly within Apple's App Sandbox boundaries.

01 // Architectural Guarantees

AUDIT // 100% LOCAL OPERATION
SEC.01

Zero Analytics SDKs

There is no Google Analytics, Segment, Sentry, Firebase, or telemetry framework linked to the executable binary. The app never phones home.

SEC.02

App Sandbox Isolation

AirPlayr runs inside macOS App Sandbox. It cannot access arbitrary filesystem directories, user documents, or keystrokes.

SEC.03

Security-Scoped Bookmarks

Files opened via drag-and-drop or file dialogs are accessed strictly via Apple's temporary security-scoped bookmarks and closed on quit.

03 // Independent Verification

INSPECTION // LITTLE SNITCH & WIRESHARK
PACKET AUDIT // REPRODUCIBLE COMMANDS WIRESHARK VERIFIABLE

You can verify AirPlayr's network traffic in real time using tcpdump or Little Snitch. Run this command while streaming a movie: 

sudo tcpdump -i any "not broadcast and not multicast and not net 192.168.0.0/16 and not net 10.0.0.0/8 and not net 172.16.0.0/12"

Result: Zero WAN packets exit your machine. All traffic remains on your local Wi-Fi router.
