Security & Privacy Architecture

AirPlayr is a 100% local, sandboxed macOS application with zero cloud accounts, zero analytics or telemetry, and strict process and network isolation.

Sandbox & Network Isolation Diagram

Defense-in-Depth Controls

Security Layer Implementation in AirPlayr v1.6.0
macOS App Sandbox Enabled with com.apple.security.app-sandbox. Entitled only for user-selected files and local network sockets. Zero access to camera, microphone, contacts, or full disk.
Isolated MKV Helpers Bundled ffmpeg and ffprobe binaries disable all network protocols, external libraries, and autodetection at compile time. Media is passed via seekable read-only file descriptors (fd:0), never shell strings.
Bounded Child Execution Helper output is capped at 2 MB and execution time is bounded to 30 seconds with automatic SIGTERM → 1-second SIGKILL escalation and guaranteed process reaping.
LAN Stream HTTP Server Binds exclusively to the active private LAN IPv4 interface (en0/en*) on an ephemeral port with a 64-character random session token. Rejects path traversal, enforces a 5s header deadline, and evicts unauthenticated idle sockets.
Temporary Cache Hygiene Segments are staged in mode-0700 directories, deleted synchronously when streaming stops, and swept on app startup via TemporaryCacheCleanup.removeAbandonedCaches().
Automatic Sleep Guard Keeps your Mac awake strictly while video or audio is actively playing or casting, and releases immediately when you pause, stop, or quit.
